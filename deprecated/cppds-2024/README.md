# Deprecated: 2024 C++ implementations (do not use)

These `.cpp` files are the earlier (2024) C++ versions of the course data
structures, for example a fixed-capacity array `Stack(int size)` with
`stackTop()`/`isFull()`, and sorting functions that return a new vector.
Their interfaces differ from the ones taught now.

The NSYSU MATH208 lectures, the C++ notebook kernel and all homework (HW3–HW5)
use only the header files in [`cppds/`](../../cppds), e.g.
`#include "pythonds3/cppds/stack.hpp"`. Each homework zip already contains
the headers it needs in `Cpp/pythonds3/cppds/`.

The files are kept here for reference only and are no longer maintained.
